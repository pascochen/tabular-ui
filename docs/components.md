## Foundational (18) — the contract

Adopted from shadcn/ui (Base UI variants, `base-mira` style) and restyled
with Tabular UI tokens. Primitive behavior (focus trapping, roving tabindex, ARIA
wiring) is solved upstream; our work is the token layer. **Never create a new
foundational component without asking. Never re-implement one inline.**

**Every part has a props type** on the package, named for the part: `SelectProps`, `SelectItemProps`, `DialogContentProps`, `MenuItemProps` and so on (since 2026-10-11). To give a part a fixed setting in product code, wrap it and pass the rest through: `function ModelSelect(props: Omit<SelectProps<string>, 'content'>)`. The roots that take a type parameter keep it (`SelectProps<Value, Multiple>`, `ComboboxProps<Value, Multiple>`, and `DialogProps`, `MenuProps` and `PopoverProps` with `<Payload>`). `apps/storybook/tests/props-types.tsx` fails the type-check if one goes missing.

Decorative unless given `aria-label`. Still frame under reduced motion. Its keyframes ship inside the component. |

Add via `pnpm dlx shadcn@latest add <component>`, then apply Tabular UI tokens.
Always pull the **Base UI** variant (`/docs/components/base/*`, never
`/radix/*`).
